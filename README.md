# LearnWell Analytics — Лабораторна робота №4

**Тема:** Розгортання моделі машинного навчання через FastAPI  
**Варіант:** Student Burnout Risk — GenAI Impact  
**Модель:** Logistic Regression (ЛР3)  
**Завдання:** Прогнозування рівня академічного вигорання студента: `Low`, `Medium`, `High`.

## 1. Запуск проєкту

Відкриваємо папку проєкту у VS Code та виконуємо в терміналі:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Після запуску відкриваємо Swagger UI:

**http://127.0.0.1:8000/docs**

Також можна запустити проєкт через `start_windows.bat`.

## 2. Робота з API

Для роботи з моделлю я реалізував такі методи:

| Метод | Адреса | Призначення |
|---|---|---|
| POST | `/train-model` | Навчання моделі |
| GET | `/example-input` | Приклад даних |
| POST | `/predict` | Прогнозування |
| GET | `/predictions` | Перегляд результатів |

**Перевірка роботи:**

1. Виконуємо `POST /train-model` для навчання моделі.
2. Через `GET /example-input` отримуємо приклад JSON.
3. Передаємо дані в `POST /predict`.
4. Перевіряємо збережений результат через `GET /predictions`.

**Приклад запиту `/predict`:**

```json
{
  "student_id": 100001
}
```

Також можна передати 12 характеристик нового студента через поле `features`.

Приклад результату прогнозування:

| Рівень | Ймовірність |
|---|---:|
| Low | 1,92% |
| Medium | 22,79% |
| **High** | **75,29%** |

Цей результат отримано для одного з перевірених прикладів із 12 характеристиками студента.

## 3. Модель та результати

Для навчання використовується **50 000 записів** із бази SQLite.

| Вибірка | Кількість |
|---|---:|
| Навчальна (90%) | 45 000 |
| Тестова (10%) | 5 000 |

Модель — `LogisticRegression(C=0.1, class_weight=None, random_state=42)`.

Для підготовки даних використовуються `SimpleImputer`, `StandardScaler` та `OneHotEncoder`. Усі етапи об'єднані в `Pipeline`.

**Результати навчання:**

| Метрика | Значення |
|---|---:|
| Accuracy | 54,20% |
| Macro F1-score | 54,16% |
| Recall High | 46,76% |
| Precision High | 67,36% |

## 5. База даних

Для зберігання інформації використовується SQLite.

| Таблиця | Призначення |
|---|---|
| `students_burnout` | Дані 50 000 студентів |
| `students_burnout_features` | Підготовлені дані ЛР2 |
| `lab3_predictions` | Прогнози з ЛР3 |
| `predictions` | Результати ЛР4 |
| `inference_inputs` | Вхідні дані запитів |
| `training_runs` | Історія навчання |
| `holdout_evaluations` | Результати тестування |

Прогнози та характеристики студентів автоматично зберігаються в базі даних.

## 6. Тестування

Для перевірки API використовується `pytest`.

Запуск тестів:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тести працюють із тимчасовою копією бази даних.

## 7. Висновок

У цій лабораторній роботі я створив API за допомогою FastAPI для моделі Logistic Regression із ЛР3.

Реалізував навчання моделі, прогнозування рівня академічного вигорання та збереження результатів у SQLite.

Також перевірив роботу API через Swagger UI та додав автоматичні тести.

У результаті отримав локальний сервіс, через який можна працювати з моделлю машинного навчання за допомогою HTTP-запитів.
